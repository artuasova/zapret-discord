# zapret: Discord only

Локальный обход DPI **только для Discord** на Windows. Никакого VPN, прокси и сторонних серверов:
пакеты модифицируются локально через WinDivert, остальной трафик не трогается.

Работает для чата, голоса, медиа и обновлений Discord. Проверено на провайдере Уфанет (ТСПУ, SNI-блокировка),
осень 2026.

## Что делает

- Перехватывает только нужные потоки: TCP `443`, `2053`, `2083`, `2087`, `2096`, `8443` и UDP `50000-50099`,
  `19294-19344`.
- Модифицирует TLS ClientHello (фрагментация + fake-пакеты) только для доменов Discord из `lists/discord-hosts.txt`.
- Голос Discord обрабатывается по L7-детектору `discord,stun` (IP discovery + STUN), включая медиа-порт `2096`.
- Всё остальное (браузер, игры, торренты) идёт мимо: без задержек, без ре-роутинга.

## Требования

- Windows 10/11 x64, права администратора.
- Антивирус может ругаться на `WinDivert64.sys` — это драйвер перехвата, не вирус. Если Defender удаляет файл,
  добавь папку `bin` в исключения.

## Установка

1. Скачай `zapret-discord-win64.zip` из [Releases](https://github.com/artuasova/zapret-discord/releases).
2. Распакуй в путь **без пробелов и кириллицы**, например `C:\zapret-discord`.
3. Правый клик на `install.bat` -> «Запустить от имени администратора».
4. В конце установщик сам проверит `discord.com`: должно быть `HTTP 200`.
5. Запусти Discord, проверь чат и голосовой канал.

Служба ставится в автозапуск (`zapret-discord`), при падении перезапускается автоматически.

## Удаление

`uninstall.bat` от имени администратора -> снимает задачи планировщика, удаляет службу и драйвер WinDivert.
Если драйвер был занят, после перезагрузки удалить ещё раз.

## Самовосстановление и трей (v1.1)

После установки добавляются две задачи планировщика:

- **`zapret-discord-watchdog`** — каждые 5 минут проверяет `discord.com/api`.
  - 1 сбой: просто отмечает.
  - 2 сбоя подряд: перезапускает службу.
  - 3 сбоя подряд: запускает auto-blockcheck, подбирает рабочую стратегию и перезапускает службу.
  - Защита: не трогает ничего, если интернет идёт через VPN/tunnel (иначе тест бессмыслен), не чаще
    одного автосвитча в час, не запускается в двух экземплярах. Всё пишет в `tools\logs\watchdog.log`.
- **`zapret-discord-tray`** — иконка в трее при входе в систему: статус, «Включить/Выключить обход»,
  «Проверить Discord», «Blockcheck», «Диагностика (zip)», «Открыть логи». Работает с правами админа,
  поэтому переключение без UAC.

Логи: `tools\logs\` (`watchdog.log`, `blockcheck-report.txt`, `strategies-history.jsonl`, `tray.log`).
Один файл для issue: `powershell -File tools\collect-diagnostics.ps1` -> zip в `tools\logs\`.

## Автоподбор стратегии (blockcheck)

У провайдеров разные DPI, поэтому одна стратегия не универсальна. В комплекте автоподбор:

```powershell
# из консоли администратора
powershell -NoProfile -ExecutionPolicy Bypass -File tools\blockcheck.ps1
```

Скрипт остановит службу, переберёт стратегии из `tools/strategies.json` (12 вариантов), проверит каждую
реальными запросами к Discord: API, сайт, CDN, gateway + WebSocket-рукопожатие (OP_HELLO), включит лучшую
и перезапустит службу. Результат — в `tools\logs\blockcheck-report.txt`.

Своя стратегия: добавить объект `{ "name": "...", "tls": "--dpi-desync=..." }` в `tools/strategies.json`.

## Проверка голоса

Голос проверяется отдельно, потому что живьём — только так честно:

```powershell
# зайди в голосовой канал Discord, скажи пару слов, затем:
powershell -NoProfile -ExecutionPolicy Bypass -File tools\voice-test.ps1
```

Скрипт смотрит: голосовые порты в конфиге службы, UDP-эндпоинты Discord и свежее `RTC_CONNECTED` в логах.
Коды: `0` — голос работает, `1` — сломан, `2` — проверить нельзя (Discord не запущен / не в канале).

Автоподбор с проверкой голоса: `tools\blockcheck.ps1 -Voice` (сначала подберёт стратегию, затем проверит
голос и при необходимости возьмёт следующую рабочую стратегию).

## Обновления

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\check-update.ps1
```

Коды: `0` — есть новая версия (печатает ссылку), `1` — стоит последняя, `2` — нет доступа к GitHub.
В трее есть пункт «Проверить обновления».

## Проверка вручную

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" https://discord.com/api/v9/gateway   # 200
sc query zapret-discord                                                     # RUNNING
```

## Если не работает

| Симптом | Что смотреть |
|---|---|
| API 000/timeout | служба не запущена, либо порты в фильтре не совпадают с стратегией |
| Работает сайт, не работает голос | UDP-порты `50000-50099` / `19294-19344`, L7 `discord,stun` |
| Работает и чат, и голос, но медиа-вложения висят | порты `2053,2083,2087,2096,8443` + hostlist `discord.media` |
| Всё работает, но через ~16 КБ обрыв | не DPI, а IP-троттлинг Cloudflare: нужен туннель (Happ/AmneziaWG/VLESS) |
| Не подключается только нужный сервис | добавь домен в `lists/discord-hosts.txt`, перезапусти службу |

Провайдеры разные: если стратегия не заходит, попробуй пресеты из `presets/` (split2, fake+md5sig, disorder).

## Состав

```
install.bat            установка службы + задач планировщика (нужен админ)
uninstall.bat          удаление
VERSION                версия сборки
bin/                   winws.exe (zapret), WinDivert, cygwin1
lists/discord-hosts.txt домены Discord, к которым применяется обход
presets/               готовые фиксированные стратегии
tools/blockcheck.ps1   автоподбор стратегии под провайдера (-Voice = с проверкой голоса)
tools/watchdog.ps1     самовосстановление (задача каждые 5 минут)
tools/tray.ps1         иконка в трее
tools/verify.ps1       быстрая проверка состояния
tools/voice-test.ps1   проверка голоса вживую
tools/check-update.ps1 проверка новой версии на GitHub
tools/collect-diagnostics.ps1  zip с диагностикой
tools/strategies.json  список проверяемых стратегий
tools/logs/            логи и отчёты
```
