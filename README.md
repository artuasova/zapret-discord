# zapret: Discord only

Локальный обход DPI **только для Discord** на Windows. Никакого VPN, прокси и сторонних серверов:
пакеты модифицируются локально через WinDivert, остальной трафик не трогается.

Работает для чата, голоса, медиа и обновлений Discord. Проверено на провайдере Уфанет (ТСПУ, SNI-блокировка),
осень 2026.

## Что делает

- Перехватывает только нужные потоки: TCP `443`, `2053`, `2083`, `2087`, `2096`, `8443` и UDP `50000-50099`,
  `19294-19344`.
- Модифицирует TLS ClientHello (фрагментация + fake-пакеты) только для доменов Discord из `lists/discord-hosts.txt`.
- Голос Discord обрабатывается по L7-детектору `discord,stun` (IP discovery + STUN), включая медиа-порт `2096`.
- Всё остальное (браузер, игры, торренты) идёт мимо: без задержек, без ре-роутинга.

## Требования

- Windows 10/11 x64, права администратора.
- Антивирус может ругаться на `WinDivert64.sys` — это драйвер перехвата, не вирус. Если Defender удаляет файл,
  добавь папку `bin` в исключения.

## Установка

1. Распакуй папку в путь **без пробелов и кириллицы**, например `C:\zapret-discord`.
2. Правый клик на `install.bat` -> «Запустить от имени администратора».
3. В конце установщик сам проверит `discord.com`: должно быть `HTTP 200`.
4. Запусти Discord, проверь чат и голосовой канал.

Служба ставится в автозапуск (`zapret-discord`), при падении перезапускается автоматически.

## Удаление

`uninstall.bat` от имени администратора -> удаляет службу и драйвер WinDivert.
Если драйвер был занят, после перезагрузки удалить ещё раз.

## Автоподбор стратегии (blockcheck)

У провайдеров разные DPI, поэтому одна стратегия не универсальна. В комплекте автоподбор:

```powershell
# из консоли администратора
powershell -NoProfile -ExecutionPolicy Bypass -File tools\blockcheck.ps1
```

Скрипт остановит службу, переберёт стратегии из `tools/strategies.json` (12 вариантов), проверит каждую
реальными запросами к Discord: API, сайт, CDN, gateway + WebSocket-рукопожатие (OP_HELLO), включит лучшую
и перезапустит службу. Результат — в `tools/blockcheck-report.txt`.

Своя стратегия: добавить объект `{ "name": "...", "tls": "--dpi-desync=..." }` в `tools/strategies.json`.

## Проверка вручную

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" https://discord.com/api/v9/gateway   # 200
sc query zapret-discord                                                     # RUNNING
```

## Если не работает

| Симптом | Что смотреть |
|---|---|
| API 000/timeout | служба не запущена, либо порты в фильтре не совпадают с стратегией |
| Работает сайт, не работает голос | UDP-порты `50000-50099` / `19294-19344`, L7 `discord,stun` |
| Работает и чат, и голос, но медиа-вложения висят | порты `2053,2083,2087,2096,8443` + hostlist `discord.media` |
| Всё работает, но через ~16 КБ обрыв | не DPI, а IP-троттлинг Cloudflare: нужен туннель (Happ/AmneziaWG/VLESS) |
| Не подключается только нужный сервис | добавь домен в `lists/discord-hosts.txt`, перезапусти службу |

Провайдеры разные: если стратегия не заходит, попробуй пресеты из `presets/` (split2, fake+md5sig, disorder).

## Состав

```
install.bat            установка службы (нужен админ)
uninstall.bat          удаление
bin/                   winws.exe (zapret), WinDivert, cygwin1
lists/discord-hosts.txt домены Discord, к которым применяется обход
presets/               готовые фиксированные стратегии
tools/blockcheck.ps1   автоподбор стратегии под провайдера
tools/strategies.json  список проверяемых стратегий
```
